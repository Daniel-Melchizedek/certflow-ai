Email Channel

Candidate sends plain-English email → Graph webhook → Service Bus → Worker → Agents → proposal back in Outlook. No portal login needed.

Portal Channel

Candidate or admin logs in via Entra SSO → Blazor wizard mirrors Pearson VUE flow → same backend API and policies as email channel.

Two Specialized Agents

Agent 1 — intent & identity (who + which exam + constraints). Agent 2 — policy validation + slot ranking + proposal drafting. Both use gpt-4o via Chat Completions with tool calling.

Observability

OpenTelemetry GenAI tracing enabled on all containers via 3 env vars. Per-agent spans and tool call spans flow to Application Insights automatically.

Single Identity

One user-assigned Managed Identity authenticates all 4 containers against SQL, Key Vault, Service Bus, Graph API, and Azure OpenAI. Zero client secrets.

Cost Controls

Scale-to-zero (minReplicas 0), SQL Basic 5 DTU (~$5/mo), Service Bus Basic, Log Analytics 7-day retention, 0.25 vCPU per container.
